# Context and Requirements for Portfolio Site Development

## 1. The Core Objective

We are building/updating my technical portfolio website. The primary goal of this site is to showcase my software projects (frameworks, TUIs, API wrappers) while explicitly framing my development methodology.

## 2. The Development Methodology: "Agentic Orchestration"

Do not refer to me as a traditional "programmer" or imply that my primary skill is manually typing syntax. My role is **Systems Architect** and **Agentic Developer**.

I build software using multi-agent workflows. I design the architecture, engineer the logic, define strict behavioral constraints, and iteratively direct AI coding agents to execute the codebase. I operate at the abstraction layer of a Senior Technical Lead—handling the conceptual heavy lifting, rigorous QA, and systems design, while the AI handles the syntax translation. The portfolio's copy, layout, and project descriptions must confidently reflect this modern, high-leverage paradigm.

## 3. Key Projects to Feature

When generating copy or structuring the project sections, use the following details:

* **The Dielectrics Framework & Anti-Sycophancy Pipeline:**
  * *Description:* A framework featuring a custom anti-sycophancy pipeline engineered to strictly constrain AI compliance-bias and disrupt default LLM behaviors.
  * *Focus:* Highlight the rigorous logic and multi-agent workflow management required to force an LLM to adhere to strict behavioral constraints.
* **Terminal User Interfaces (TUIs) & API Wrappers:**
  * *Description:* Custom-built TUIs and full-stack API wrappers designed to handle I/O operations and interface seamlessly with the broader systems I architect.
  * *Focus:* Emphasize the architectural design and system integration capabilities.

## 4. Tone and Copywriting Directives

* **Action Verbs to Use:** Architected, Engineered, Directed, Designed, Evaluated, Orchestrated.
* **Concepts to Emphasize:** Systems-thinking, cognitive labor, abstraction layers, logic formulation, QA, and constraint design.
* **What to Avoid:** Apologetic language about not writing the syntax manually. This methodology is a feature and a distinct advantage, not a shortcut.

## 5. Execution Instructions for the Agent

As you build the HTML/CSS/JS (or relevant framework) for this portfolio:

1. Ensure the UI/UX reflects a clean, architect-level professionalism.
2. Draft placeholder or final copy for the project sections using the exact framing outlined above.
3. Ask me for approval on the structural layout before finalizing the specific wording of the project cards.
